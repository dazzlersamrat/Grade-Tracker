# Problem Statement

## Problem
Students and teachers find it difficult to manually track and calculate 
grades for multiple students across multiple subjects. This often leads 
to errors and wastes time.

## Scope
This project is a command-line application that allows users to:
- Add students to the system
- Enter subject marks for each student
- Automatically calculate averages and grades
- View a detailed report for any student
- Save data so it is not lost when the app is closed

## Target Users
- Teachers in schools and colleges
- Students who want to track their own marks
- Anyone who needs a simple grade management tool

## High Level Features
1. Student Management - Add and list students
2. Marks Entry - Enter marks for 5 subjects with validation
3. Grade Calculation - Automatically calculate average and assign grade
4. Report Generation - View formatted report for any student
5. Data Persistence - Save and load data from a file
